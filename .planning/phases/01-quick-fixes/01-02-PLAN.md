<objective>
Two small parity fixes that share no files between platforms but belong together as the "validation + queue integrity" wave:

1. C-02 — Windows must refuse `http://` custom server URLs, matching macOS `validatedBaseURL()` which throws `httpsRequired` unless `url.scheme?.lowercased() == "https"`.

Purpose: Close cross-platform parity gaps C-02 and C-03. Windows is the reference for C-03 (already id-based, limit 5); macOS is the side being aligned. macOS is the reference for C-02 (https enforcement); Windows is the side being aligned.
Output: https-enforced Windows base URL; id-based macOS queue identity; one retry-limit constant value (5) on both platforms.
</objective>
