## Interaction Patterns

### Directory List
- macOS: `List` with swipe-to-delete disabled; use trailing action button (trash icon) per row. Confirm delete with `confirmationDialog` (not `Alert`). Tap row to open `PersonEditView` as sheet.
- Windows: Row with hover-reveal delete icon (Fluent `Delete24Regular`). Click row to open edit panel/modal. Confirm delete with inline "Weet je het zeker?" + "Verwijderen" / "Annuleren".
- Search: macOS `searchable()` modifier on list. Windows: `input` field above list with `onChange` filter. Filter on name + aliases + email (case-insensitive).

### PersonEditView / PersonEditModal
- Tag fields (aliassen, expertiseTags): comma-separated `TextField` — identical to `ProfileSettingsView.swift:100,116`. Placeholder: "grafisch ontwerp, marketing, IT (kommagescheiden)". Load: `.joined(separator: ", ")`. Save: `splitAndTrim`.
- Intern/extern/onbekend: macOS `Picker` with `.segmented` style showing three options: "Intern" / "Extern" / "Onbekend". Windows: `<select>` or three radio buttons. Default to "Onbekend" for new entries.
- Save button: `PrimaryButtonStyle` (macOS) / `.btn.btn-primary` (Windows). Shows loading state during async write. Shows "Opgeslagen" + checkmark for 2s on success (matches ProfileSettingsView pattern).
- Unsaved changes: no confirmation on dismiss in Phase 2 — keep simple.

### SeedReviewSheet
- Triggered: when recording stops and `activeMeeting` has attendees not yet in the directory.
- Layout: title "Nieuwe deelnemers gevonden", subtitle with count, scrollable list of person rows, primary "Voeg X personen toe" / "Voeg 1 persoon toe" button, "Overslaan" text button.
- Per-person row: checkbox (default ON), display name (or email prefix if no displayName), full email in secondary label. User can uncheck to exclude.
- Disabled state for "Voeg toe" button when zero items checked.
- Animation: macOS `.sheet` presentation; Windows: modal overlay with `--radius-md` border-radius.

## States Required

Each screen must handle all states listed:

### PeopleDirectoryView / PeoplePage

| State | Trigger | Visual |
|-------|---------|--------|
| Loading | Initial fetch from store | macOS: `ProgressView()` centered; Windows: skeleton rows or spinner |
| Empty | No `isSelf==false` profiles exist | Empty state illustration-free: heading + body copy + CTA button |
| Populated | 1+ directory entries | List rows: name (bodyMedium), role + org (footnote, labelSecondary), status dot |
| Searching | Search field has text | Filtered list; if no matches: "Geen resultaten voor '{query}'" |
| Error | Store fetch failed | Error message inline, no crash |

### PersonEditView / PersonEditModal

| State | Trigger | Visual |
|-------|---------|--------|
| New person | Add button tapped | All fields empty, "Onbekend" selected for isInternal |
| Editing | Row tapped | Fields pre-populated from `PersonProfile` |
| Saving | Save tapped | Button shows loading indicator, fields disabled |
| Saved | Write succeeded | "Opgeslagen" + checkmark for 2s, then dismiss |
| Error | Write failed | Error text in statusError color below button |

### SeedReviewSheet

| State | Trigger | Visual |
|-------|---------|--------|
| Shown | Recording stops with new attendees | Sheet with person list |
| All unchecked | User unchecks all rows | Primary button disabled |
| Partial selection | Some rows checked | Button label shows checked count |
| Saving | Primary button tapped | Loading state, rows disabled |
| Done | Save succeeded | Sheet dismisses |
