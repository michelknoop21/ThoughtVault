# Sneltoetsen

De sneltoetsen brengen je vooral van het ene scherm naar het andere. De cijfers volgen de volgorde van de zijbalk.

## Tussen schermen wisselen

::: macos
| Sneltoets | Wat er gebeurt |
|-----------|----------------|
| `Cmd+1` | Opent **Home** |
| `Cmd+2` | Opent **Opnemen** |
| `Cmd+3` | Opent **Taken** |
| `Cmd+4` | Opent **Notulen** |
| `Cmd+5` | Opent **Mensen** |
| `Cmd+6` | Opent **Instellingen** |
| `Cmd+7` | Opent **Admin**, alleen als je bent ingelogd met een beheerdersaccount |
| `Cmd+R` | Opent **Opnemen** |
| `Shift+Cmd+S` | Klapt de zijbalk in of uit |

`Cmd+R` opent het opnamescherm en start de opname niet. Starten doe je daarna op dat scherm, zie [Opnemen](opnemen.html).
:::

::: windows
| Sneltoets | Wat er gebeurt |
|-----------|----------------|
| `Ctrl+1` | Opent **Home** |
| `Ctrl+2` | Opent **Opnemen** |
| `Ctrl+3` | Opent **Taken** |
| `Ctrl+4` | Opent **Notulen** |
| `Ctrl+5` | Opent **Mensen** |
| `Ctrl+6` | Opent **Instellingen** |
| `Ctrl+N` | Opent **Opnemen** |
| `Ctrl+Shift+S` | Klapt de zijbalk in of uit |

`Ctrl+1` tot en met `Ctrl+6` staan ook in de zijbalk, achter de naam van elk onderdeel. `Ctrl+N` opent het opnamescherm en start de opname niet. Starten doe je daarna op dat scherm, zie [Opnemen](opnemen.html).
:::

::: ios
De app heeft op iPhone en iPad geen eigen sneltoetsen. Je wisselt van scherm met de tabbalk onderin.
:::

## Zoeken, afdrukken en opnemen

::: macos
| Sneltoets | Wat er gebeurt |
|-----------|----------------|
| `Cmd+P` | Drukt de notule af die open staat. Hetzelfde als **Afdrukken…** in de menubalk |
| `Shift+Cmd+R` | Hoort bij **Start opname** in het menu van het ThoughtVault-pictogram in de menubalk |

`Cmd+P` werkt alleen als er een notule open staat. **Start opname** staat alleen in het menubalkmenu zolang er geen opname loopt.
:::

::: windows
| Sneltoets | Wat er gebeurt |
|-----------|----------------|
| `Ctrl+F` | Opent **Notulen**. Sta je al in de lijst met notulen, dan springt de cursor naar het zoekveld |
| `Esc` | Sluit een geopend dialoogvenster |
:::

::: ios
Op iPhone en iPad zijn hier geen sneltoetsen voor.
:::

## Als een sneltoets niets doet

::: windows
De sneltoetsen voor navigatie werken niet zolang de cursor in een tekstveld staat. Klik eerst naast het veld en probeer het opnieuw. `Ctrl+Shift+S` werkt wel vanuit een tekstveld, net als `Ctrl+F` in de lijst met notulen.
:::

::: macos
`Cmd+7` doet niets als je account geen beheerdersrol heeft, en `Cmd+P` doet niets zonder geopende notule.
:::

::: ios
Dit geldt niet voor iPhone en iPad.
:::
