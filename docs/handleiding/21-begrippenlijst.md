# Begrippenlijst

De termen staan per onderwerp bij elkaar. Waar een term een eigen plek in de app heeft, staat die erbij.

## Opnemen en verwerken

| Term | Betekenis |
|------|-----------|
| Engine | De techniek die op een Mac, iPhone of iPad de transcriptie doet: WhisperKit, met een model dat je downloadt, of Apple Spraakherkenning, zonder download. |
| Gecombineerd | Opnamebron op Mac en Windows die je microfoon en het geluid van je computer samen opneemt. Bedoeld voor videocalls. |
| Lokaal | Verwerking op je eigen apparaat. De audio wordt niet verstuurd. |
| Cloud | Verwerking via de ThoughtVault-server: de opname wordt geüpload. Hiervoor log je in met een account. |
| Opgeslagen opnames | De lijst op het scherm **Opnemen** met opnames die bewaard zijn en die je opnieuw kunt verwerken. |
| Systeemaudio | Het geluid dat je computer afspeelt, zoals de stemmen van de andere deelnemers in een videocall. |
| Taak | Een opname die wordt verwerkt. De voortgang zie je op het scherm **Taken**. |
| Transcriptie | Het omzetten van audio naar tekst. Ook: de letterlijke tekst die daaruit komt, het transcript. |
| Transcriptiemodel | Het spraakmodel dat de transcriptie op je apparaat doet. Je downloadt het één keer. Een groter model neemt meer schijfruimte in. |

## Notulen

| Term | Betekenis |
|------|-----------|
| Aanbieder | De dienst of het programma dat de notulen schrijft op basis van het transcript. Je kiest hem bij **Instellingen** > **Verwerking**. |
| API-sleutel | Een code die je bij een cloudaanbieder aanmaakt en in de app plakt. Daarmee verwerkt de aanbieder je transcript op jouw rekening. |
| Apple Intelligence | De taalfunctie van Apple die notulen op je Mac, iPhone of iPad zelf schrijft. Niet beschikbaar op Windows. |
| Cloudaanbieder | Een aanbieder die het transcript op zijn eigen servers verwerkt. Je gebruikt hem met je eigen API-sleutel. |
| LM Studio | Programma waarmee je een taalmodel op je eigen computer draait. Standaardadres: `http://localhost:1234`. |
| Model | Het taalmodel dat de aanbieder gebruikt. Het model bepaalt mee hoe volledig de notulen zijn. |
| Notulen | Het verslag dat de aanbieder van het transcript maakt. Eén verslag heet in de app een notule. |
| Ollama | Programma waarmee je een taalmodel op je eigen computer of server draait. Standaardadres: `http://localhost:11434`. Ollama Cloud is de variant waarbij het model bij Ollama zelf draait, met een API-sleutel. |
| Profiel | De opzet voor een soort gesprek: het bepaalt de opbouw en toon van de notulen. Zie [Profielen](profielen.html). |
| Regenereer | De knop waarmee je notulen opnieuw laat schrijven uit dezelfde transcriptie. |
| Woordenlijst | Je eigen lijst met namen en termen en hun verkeerde spellingen. De app corrigeert die in volgende notulen. |

## Instellingen en hulp

| Term | Betekenis |
|------|-----------|
| Foutrapport | Een bericht dat de app zelf naar de ontwikkelaar stuurt als een opname, transcriptie of notule mislukt, of na een crash. Uit te zetten bij de instellingen voor support. |
| Klikpad | De reeks schermen en knoppen die je kort voor een fout gebruikte. Het gaat mee in een foutrapport. |
| Logbestand | Het technische logboek van de app op je apparaat. Je bekijkt het met **Toon logbestand**. |
| Melding | Een fout, idee of vraag die je vanuit de app naar de ontwikkelaar stuurt. Antwoorden lees je in **Mijn meldingen**. |
| Obsidian | Notitie-app. ThoughtVault kan elke nieuwe notule automatisch naar je Obsidian-vault schrijven. |
| Permissies | De toestemmingen van het besturingssysteem die de app nodig heeft, zoals toegang tot de microfoon. Op iPhone en iPad heet dit **Rechten**. |
| Snelle setup | Het blok bovenaan **Verwerking** op Mac en Windows dat instellingen voorstelt op basis van je computer. |
| Vault | De map waarin Obsidian je notities bewaart. |
